# Documentation rules

Use ASD-STE100 for repository documentation. Use short sentences, active voice, and one term for each concept. Keep technical names exact. Remove repeated text. Do not remove scope, units, conditions, or evidence to reduce length.

Keep current behavior in the subject document. Put stage history and past measurements in the issue or the pull request, not in a document. Update the subject document when behavior changes. Link to evidence instead of copying it.

Resolve a conflict against pinned source and an independent check. Update the affected document with the correction.
